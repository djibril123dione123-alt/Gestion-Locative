# Design system

Samay Këur doit ressembler à une console proptech/fintech premium : calme, dense, lisible et utile sur le terrain.

## Principes

- Clarté avant décoration.
- Densité utile, surtout mobile.
- Hiérarchie forte : statut, montant, action.
- Orange contrôlé pour paiement/action.
- Vert profond pour confiance, structure et patrimoine.
- Aucun scroll horizontal non voulu sur les pages prioritaires.

## Navigation

- sidebar structurée par domaines ;
- un seul groupe ouvert si possible ;
- bottom nav mobile compacte ;
- zone utilisateur cliquable ;
- notifications intégrées, pas une entrée lourde.

## Tables et cartes mobiles

Desktop :

- table lisible ;
- headers sobres ;
- actions compactes.

Mobile :

- cartes ;
- recherche sans overflow ;
- filtres en ligne quand possible ;
- actions groupées ;
- actions sensibles dans un menu si nécessaire.

## Documents PDF

Les PDF doivent être :

- premium mais imprimables ;
- bordures visibles sans excès ;
- QR intégré ;
- mentions compactes ;
- tableaux alignés ;
- footer institutionnel.

## États réseau

- pas de skeleton infini ;
- données cache clairement signalées ;
- bouton Réessayer ;
- actions sensibles désactivées hors ligne.

## À éviter

- grands blocs décoratifs qui mangent la page ;
- cartes imbriquées ;
- orange dominant ;
- hero marketing dans l'app métier ;
- texte explicatif excessif dans les interfaces.
