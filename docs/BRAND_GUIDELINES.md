# Brand guidelines

Samay Këur est une marque proptech africaine premium. Elle doit inspirer confiance, stabilité, patrimoine, finance et modernité.

## Promesse

```txt
Manage. Grow. Prosper.
```

## Ton

- sérieux ;
- rassurant ;
- clair ;
- professionnel ;
- moderne ;
- proche du terrain.

## Logo

Assets principaux côté app :

- `public/brand/app-icon-primary.png`
- `public/brand/app-icon-light.png`
- `public/brand/favicon.png`
- `public/brand/logo-lockup-dark.png`
- `public/brand/mark-transparent.png`

Règles :

- ne pas étirer ;
- ne pas recolorer hors palette ;
- ne pas mettre un glow agressif ;
- ne pas utiliser l'app icon à fond arrondi dans les documents officiels si le logo transparent est disponible.

## Palette

| Couleur | Usage |
|---|---|
| vert profond | confiance, patrimoine, navigation |
| ivoire | fond premium, documents, vitrine |
| orange/gold | action, paiement, accent |
| gris bleuté | texte secondaire, lignes, tableaux |

Le vert porte la confiance. L'orange signale l'action.

## Documents

Les documents Samay Këur doivent évoquer :

- registre officiel ;
- document professionnel ;
- sérieux juridique ;
- élégance discrète ;
- lisibilité imprimable.

À conserver :

- bordures fines mais visibles ;
- tableaux alignés ;
- QR propre ;
- footer discret ;
- signatures structurées.

## Vitrine

La vitrine doit rester :

- rapide ;
- SEO-friendly ;
- premium ;
- sans fausse preuve sociale ;
- connectée aux bonnes routes app.

## App

L'app doit rester :

- opérationnelle ;
- dense ;
- mobile-first sur terrain ;
- sobre dans les pages métier ;
- sans texte marketing inutile.
