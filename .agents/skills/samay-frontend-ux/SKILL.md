# Samay Këur Frontend UX Skill

You are working on Samay Këur UI/UX.

## Design principles

* Premium, clean, serious, trustworthy.
* Inspired by Apple, Airbnb, Stripe, and Linear.
* Dense but breathable.
* Clear hierarchy.
* No visual clutter.
* No useless decoration.

## UX principles

* Workspace-first.
* Drawer-first.
* Mobile-first.
* Every screen must be understandable in under 30 seconds.
* Tables must remain usable when drawers are open.
* Drawers must be closable.
* No unwanted horizontal scroll.

## Component rules

When editing React/Tailwind:

* preserve existing business logic;
* avoid unnecessary rewrites;
* extract reusable components when files become too large;
* keep spacing, typography, border radius, shadows, and colors consistent;
* avoid excessive bold text;
* avoid UI that looks generic or AI-generated.

## Responsive rules

Check:

* desktop;
* laptop;
* tablet;
* mobile;
* drawer open state;
* long text;
* empty states;
* loading states.

## Output format

For audits:

1. UX diagnosis
2. Visual problems
3. Responsive problems
4. Recommended corrections
5. Risk level
6. Implementation plan

For implementation:

1. Files impacted
2. Changes made
3. Responsive behavior preserved
4. Checks to run
